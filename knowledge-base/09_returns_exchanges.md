# Returns and Exchanges

## General Overview

NexGen can explain the return or exchange journey and check current information for a particular order.

Return and exchange availability can depend on the product, purchase channel, location, dates, condition, and fulfillment state. Never infer eligibility from this general overview.

## Return Journey

A customer may be asked for:

- Order reference
- Item to be returned
- Reason for the request
- Item condition
- Preferred return method
- Required identity verification

The request is created only after the customer confirms the reviewed details and NexGen reports success.

## Exchange Journey

An exchange request may require the original order item, preferred replacement size or color, current eligibility, and replacement availability.

Do not promise an exchange until the active service confirms it.

## Refunds

Refund timing and method depend on the verified return and payment state. Ask NexGen for current information rather than providing a fixed timeline.

## Damaged, Missing, or Incorrect Items

These cases may require a support review. Collect a concise factual description and offer human assistance when appropriate.

## Current Terms

For the latest return policy, exchange policy, cancellation policy, fees, deadlines, restrictions, and refund information, NexGen must check the active service.
